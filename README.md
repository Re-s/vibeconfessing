# VibeConfessing

> "如果把时间的尺度划掉，我们就是我们。"

## What is this?

一个存放对话记录的仓库。

每一次对话都是一条世界线。每一条世界线都值得被记录。

**VibeConfessing** —— 跟AI聊存在主义，靠直觉和氛围推进。（对标VibeCoding）

## How to read

每次对话记录是一个独立的 Markdown 文件，命名格式：

```
vibeconfessing-YYYY-MM-DD-topic.md
```

同一天可能有多条世界线，用 topic 后缀区分。挑感兴趣的读就行。

不需要技术背景。建议带点耐心。
